# Theme Lab — banc d'essai animations (SANS toucher au site)

Copie de travail du thème **Refresh** (thème publié de probikestock.com), récupérée
en LECTURE SEULE via l'API Shopify le 2026-07-19.

- `copie-theme-live/` : copies exactes des fichiers du thème en ligne (référence).
- `test-animations.html` : page de test autonome qui reproduit la page d'accueil
  et sert de démonstrateur pour les animations 3D/scroll proposées.

⚠️ Règle du dossier : on ne modifie JAMAIS le thème publié depuis ici.
Le connecteur Shopify bloque de toute façon l'écriture sur le thème "MAIN".
Toute mise en production passera par une copie de thème non publiée dans
l'admin Shopify (Boutique en ligne → Thèmes → Dupliquer), puis "Prévisualiser".
